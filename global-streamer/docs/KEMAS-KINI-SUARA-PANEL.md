# Kemas kini masa nyata, format TikTok/YouTube, capture card, Game PC, panel kedua, suara dan bot

## 1. Kemas kini app (masa nyata)
Alur: anda tolak kod ke cabang `main` atau `ccr-*` -> GitHub Actions (`build-windows.yml`) membina pemasang Windows (versi automatik `0.2.<nombor run>`) -> menerbitkan **GitHub Release** (pemasang, `latest.yml`, blockmap, dan salinan `Global-Streamer-Setup.exe`) -> app yang dipasang menyemak Release terkini **setiap 5 minit**, apabila tetingkap difokus semula, dan 8 saat selepas dibuka -> memuat turun di latar -> butang di bar atas bertukar **"Kemas kini X sedia: klik untuk pasang"** -> klik: pasang senyap dan app dibuka semula (jika sedang LIVE, app bertanya dahulu).
* Butang kemas kini sentiasa kelihatan di bar atas (versi semasa; klik = semak sekarang). Tetapan > Kemas kini: semak sekarang / matikan semakan automatik.
* `firebase.json`: `/updates/*` dialihkan ke GitHub Releases (untuk app lama yang masih menyemak `global-streamer.web.app/updates`); pautan muat turun tetap: `https://global-streamer.web.app/download/windows`.
* Jarak masa dari tolak kod hingga app menawarkan kemas kini: binaan ~3 minit + semakan paling lama 5 minit.
* Versi web (`global-streamer.web.app`) dikemas kini melalui `firebase deploy --only hosting`; halaman utama tidak disimpan dalam cache pelayar.
* Pemasang belum ditandatangani (kod): SmartScreen memberi amaran. Pilih "Only for me" semasa memasang supaya kemas kini tidak meminta kata laluan admin.

## 2. Format siaran dan Template
* Bar atas: suis **TikTok (9:16)** / **YouTube · FB (16:9)**. Menukar format serta-merta; susun atur setiap format **disimpan** dan dipulihkan apabila kembali. Ditolak semasa LIVE.
* Dock **Template** (sebelah Audio Mixer): tab TikTok dan YouTube · FB; klik satu template untuk menggunakannya pada scene aktif (peranti video dikekalkan; pengesahan diminta kerana susun atur scene diganti).

## 3. Capture card dan Game PC
* **Capture Card (game)**: hanya peranti capture card (HDMI) disenaraikan. Webcam tidak disenaraikan di sini (guna sumber **Kamera / Webcam**). Pengenalan berdasarkan nama peranti (Elgato, AVerMedia, Cam Link, "USB Video", "HDMI"…). Peranti yang tidak dikenali ada di bahagian "Peranti video lain".
* **Game PC (pilih tetingkap)**: pilih tetingkap tertentu (Steam, game) seperti Window Capture OBS; hanya tetingkap itu disiarkan. Biarkan tetingkap tidak diminimumkan. Tetingkap app ini sendiri disembunyikan daripada senarai.

## 4. Panel Chat/Game/Meta ke skrin kedua
Butang ikon di penjuru tab panel kanan mengeluarkan panel ke tetingkap baharu. Tarik ke skrin/PC kedua. Chat, alert dan kawalan terus hidup. "Masukkan semula ke app", menutup tetingkap, atau butang "Kembalikan" di bar atas memulangkan panel. Saiz/kedudukan tetingkap diingati. Modal (cth Sambungan chat) dibuka dalam tetingkap yang sedang digunakan. Toast makluman muncul di tetingkap utama.

## 5. Suara dan bot (Audio Mixer > Suara & Bot)
* **Efek melalui suara** (tanpa papan kekunci): sebut, atau biarkan game menyebut ("Double Kill", "Victory", "Defeat", "You have been slain"), dan efek keluar. Frasa boleh diubah; "double kill" mengatasi "kill"; jeda 3 s per efek; ketepatan minimum boleh dilaras.
* **Bot**: nama ditetapkan sendiri (cth Jarvis). "Jarvis, siapa noob?" -> bot menjawab daripada senarai soalan/jawapan. Jawapan boleh memakai data game: `{kill} {mati} {assist} {menang} {kalah} {streak} {toppick} {topban} {nama}`. Jawapan dipaparkan pada siaran (gelembung) dan disuarakan; pilihan memasukkan suara bot ke dalam siaran (app Windows).
* **Gelembung jawapan bot** (gaya komik, kecil): jika kamera BESAR (cth template TikTok) gelembung di bawah dalam kotak kamera; jika kamera KECIL gelembung diletakkan tengah-bawah di kotak besar (paparan game) dengan ekor menghala ke kamera, dianjak ke atas untuk mengelak widget, supaya tidak menutup muka streamer. Jawapan panjang memanjang ke sisi dahulu, kemudian huruf dikecilkan; gelembung dipotong pada kotak hosnya.
* **Suara bot** (Suara & Bot > Bot suara): pilih **Perempuan** atau **Lelaki**, dan penyedia:
  * *Suara sistem* (percuma, tanpa internet): memilih suara Melayu mengikut jantina jika dipasang (Windows: Malay), jika tidak suara Inggeris mengikut jantina. Dalam app Windows, "Masukkan suara bot ke dalam siaran" menjana WAV supaya penonton mendengarnya.
  * *ElevenLabs* (tier percuma, suara AI semula jadi, Bahasa Melayu melalui model multilingual): daftar di elevenlabs.io, Profile > API Keys, tampal kunci. 10,000 aksara sebulan; jawapan yang sama dicache (tiada kuota dua kali); teks dihadkan 280 aksara; "Semak kuota" memaparkan baki. Audio terus masuk ke dalam siaran. Jika kunci tidak sah/kuota habis/tiada internet, bot jatuh ke suara sistem dengan mesej jelas. Kunci disimpan disulitkan oleh Windows (app) atau dalam memori sahaja (web). ID suara lelaki/perempuan boleh diganti (lanjutan).
  * Belum diuji dengan akaun/kunci ElevenLabs sebenar (diuji dengan pelayan tiruan). Syarat tier percuma ElevenLabs: lihat elevenlabs.io (penggunaan komersial dan kredit mungkin dihadkan).
* Animasi gelembung: berasaskan masa (licin pada 30/60/120 fps, tajam pada 4K kerana dilukis secara vektor): letup masuk dengan spring teredam dan goyang kecil dari hujung ekor, garis letupan, terapung halus, tulisan ditaip perlahan-lahan, keluar mengecil dan pudar. Warna mengikut tema semasa (bukan putih; teks hitam/putih ikut kontras), bayang keras dan tekstur titik gaya komik.
* Kotak **Uji tanpa suara** menaip frasa untuk memeriksa tetapan tanpa mikrofon.
* Pengecam: **app Windows** = pengecam suara Windows (System.Speech) luar talian melalui PowerShell, disuap daripada saluran Audio Mixer (mikrofon dan/atau bunyi game). Memerlukan pengecam suara Windows (lazimnya English). **Pelayar** = Web Speech API Chrome (mikrofon lalai, perlukan internet).
* Had jujur: kualiti pengecaman bergantung pada pengecam Windows yang dipasang dan bunyi (muzik/letupan game mengurangkan ketepatan). Bahasa Melayu tidak disertakan dalam Windows secara lalai: tulis ejaan sebutan Inggeris sebagai frasa tambahan. Bunyi game dan suara mikrofon yang bertindih tidak dipisahkan. Pengumuman musuh juga boleh mencetuskan efek jika frasa sama disebut.
* Diuji: logik padanan, bot, aliran PCM 16 kHz, protokol proses dan suara bot dengan pengecam/sintesis tiruan (`npm run test:voicehost` + ujian UI). **Belum diuji dengan pengecam suara Windows sebenar dan mikrofon sebenar.**

## 6. Rakaman, audio jelas, Sediakan Live, susun atur panel, pengumum
* **Rakaman** (butang REC dan anak panah di sebelahnya): *Paparan penonton (Program)*, *Seluruh skrin (semua aplikasi)* atau *Satu tetingkap*. Mod skrin penuh merakam apa sahaja di skrin (buka YouTube, presentation, mana-mana aplikasi) walaupun app ini dikecilkan; bar REC kecil sentiasa di atas (tidak muncul dalam rakaman) dengan butang "Henti & simpan". Dalam app Windows rakaman ditulis terus ke `Videos\GlobalStreamer` (tidak memenuhi RAM) dan tempoh/carian dibetulkan selepas selesai. Pilihan: rakam bunyi komputer (guna fon kepala), kecilkan app semasa rakam skrin. Mod Program berhenti dikemas kini jika app dikecilkan (kanvas tidak dilukis); gunakan mod skrin penuh untuk itu.
* **Suara jelas**: mikrofon menggunakan penapis bunyi latar, pembatalan gema dan kelantangan automatik pelayar, penapis frekuensi rendah, pemampat dan penguat; keluaran siaran/rakaman ada had puncak dan pemotong lembut (tiada retak). Bunyi efek (beep) TIDAK dirakam/disiarkan secara lalai (Tetapan > Audio dan rakaman); suara bot/pengumum sentiasa masuk. Gunakan fon kepala supaya mikrofon tidak menangkap pembesar suara.
* **Siaran langsung (butang "Sediakan Live" DIPADAM)**: Server URL dan Stream Key setiap platform kini ada di panel kanan > tab Chat > TikTok / Facebook / YouTube (kad "Siaran langsung"); butang + menambah aplikasi lain (Kick, Twitch, Shopee Live...) dengan URL dan key sendiri. Setiap platform ada Server URL dan Stream Key sendiri. YouTube dan Facebook: hanya Stream Key diperlukan (URL lalai diisi automatik; boleh diganti). TikTok dan RTMP lain: Server URL dan Stream Key kedua-duanya wajib. Memasukkan key menghidupkan platform; MULA LIVE terus bermula jika semua platform yang dihidupkan lengkap (jika tidak, wizard dibuka pada langkah Platform dengan senarai yang kurang).
* **Susun atur panel**: tarik pemisah antara panel (Scene, Sumber, Sifat, Audio Mixer, Template), tinggi bahagian bawah dan lebar panel kanan; tarik tajuk panel untuk menukar kedudukan. Panel tidak boleh dikeluarkan atau dikecilkan sehingga hilang (had minimum). Klik dua kali pemisah = lalai; Tetapan > Susun atur panel > Tetapkan semula.
* **Pengumum efek**: kill, first blood, double kill, triple kill, maniac, savage, killing spree, legendary, shutdown, mati, victory, defeat dan item penuh DISEBUT (bukan beep) melalui butang, pengesan skrin atau ujian; teks dan bahasa (English/Melayu) boleh diubah; bunyi beep sandaran jika suara gagal. Dengan penyedia AI, frasa dijana awal supaya main serta-merta.
* **Penyedia suara bot/pengumum** (pilih Perempuan atau Lelaki): *Suara sistem* (percuma, tanpa internet, serta-merta), *Microsoft Azure Speech* (tier percuma 500,000 aksara/bulan; suara neural Melayu ms-MY-OsmanNeural lelaki dan ms-MY-YasminNeural perempuan; perlu akaun Azure, sumber Speech "Free F0", Key 1 dan Region) dan *ElevenLabs* (tier percuma 10,000 aksara/bulan). Permintaan dibuat dari proses utama app Windows supaya kunci tidak melalui halaman web. Titik akhir tidak rasmi "Baca Kuat" Edge sengaja TIDAK digunakan (ia menyamar sebagai pelayar Edge).
* Suara Melayu pada suara sistem: Windows mungkin tiada suara Melayu; pasang di Tetapan > Masa & bahasa > Pertuturan > Tambah suara (Malay). Jika tiada, suara Inggeris digunakan.

## 7. Banner/video footer sendiri dan suara Melayu Malaysia
* **Banner / Video sendiri**: Sumber > + > "Banner / Video sendiri (imej, GIF, video)". Menerima imej (PNG/JPG), GIF animasi dan video (WebM/MP4/MOV) sebarang saiz; diletakkan di footer (menggantikan bar teks), boleh diseret dan diubah saiz bebas; butang "Letak di footer", "Nisbah asal", "Muat/Penuhi". Kotak "Sembunyikan bar teks (INFO / Welcome) dan banner promosi" mematikan bar lama. App Windows mengingati fail video/GIF mengikut laluan; versi web hanya mengingati imej kecil (video perlu dipilih semula).
* **Bahasa suara = bahasa teks**: ayat Melayu disebut dengan suara Melayu (ms-MY), ayat English dengan suara English, ikut jantina yang dipilih. Suara Indonesia tidak pernah digunakan sebagai ganti Melayu. Suara sistem Windows mungkin tiada suara Melayu (terutama perempuan): app memaparkan amaran jelas; Microsoft Azure (percuma) memberi suara Melayu Malaysia asli lelaki (Osman) dan perempuan (Yasmin).
* **Emosi**: Victory gembira (lebih laju dan tinggi), Defeat suram (perlahan dan rendah), Kill teruja. Teks pengumum lalai ialah Bahasa Melayu Malaysia.

## 8. ElevenLabs suara Melayu, butang + platform, "Hidupkan bot" terus berfungsi
* **Sambung ElevenLabs (suara Melayu lelaki + perempuan)**: Audio Mixer > Suara & Bot > Atur… > Suara bot. Tampal kunci API ElevenLabs di kotak "Suara lebih semula jadi: sambung ElevenLabs" dan tekan "Sambung dan cari suara". App bertukar ke ElevenLabs, memeriksa suara dalam akaun dan perpustakaan awam (penapis bahasa Melayu, lelaki dan perempuan), menambah suara terbaik ke akaun anda dan menetapkannya. Senarai calon dengan butang ▶ (dengar) dan "Guna" boleh ditukar bila-bila ("Cari suara Melayu (lelaki & perempuan)"). Aplikasi tidak boleh menyambung ke akaun ElevenLabs tanpa kunci API anda; kunci disimpan disulitkan oleh Windows, bukan dalam fail tetapan.
* **Had jujur**: pelan percuma ElevenLabs mungkin tidak membenarkan suara perpustakaan digunakan melalui API; jika begitu app jatuh balik ke suara dalam akaun (premade, bercakap Melayu melalui model multilingual, loghat mungkin tidak 100% Malaysia). Untuk suara Melayu Malaysia asli lelaki (Osman) dan perempuan (Yasmin) secara percuma, guna Microsoft Azure Speech (F0).
* **Butang + (platform lain)**: dialog dalam app (bukan `prompt()` yang tidak berfungsi dalam Electron) menyenaraikan platform yang memberi RTMP Server URL + Stream Key: Twitch, Kick, Shopee Live, Instagram Live, X Live, Trovo, Restream, Vimeo Live, Dailymotion, LinkedIn Live, Rumble dan "RTMP lain" (nama sendiri). Setiap kad memberi panduan di mana mendapatkan URL dan key serta pautan ke dashboard; Twitch/Trovo/Restream/Vimeo/Dailymotion ada URL lalai (hanya key diperlukan).
* **Hidupkan bot**: satu klik menghidupkan pengecam, bot dan suara bot, menyambung mikrofon lalai secara automatik (tiada langkah Audio Mixer), dan bot menyebut "Hai, saya Jarvis. Saya sedia, panggil nama saya." Menyebut nama bot sahaja dijawab "Ya?" (boleh diubah) dan bot menunggu soalan. Amaran merah "pilih input mikrofon" tidak lagi muncul; mesej hanya dipaparkan jika mikrofon benar-benar ditolak oleh sistem.
