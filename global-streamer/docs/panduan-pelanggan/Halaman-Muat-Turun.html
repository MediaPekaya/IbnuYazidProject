Bahagian 1: Muat turun

  1. Buka email anda dan cari email daripada kami yang mengandungi pautan muat turun.

  2. Salin pautan di bawah. Tekan butang Salin Pautan dan pautan terus disalin.

    Pautan muat turun https://github.com/GeniusDigitalDeveloper/global-streamer-releases-exe-apps/releases/latest/download/Global-Streamer-Setup.exe
    Buka terus

  3. Buka Google Chrome di komputer Windows anda.

  4. Klik pada bar alamat di bahagian atas Chrome, kemudian tampal (paste) pautan tadi dengan menekan Ctrl + V.

  5. Tekan Enter.

    (Fail Global-Streamer-Setup.exe akan dimuat turun secara automatik.)

    Jika Chrome menunjukkan amaran "is not commonly downloaded", klik ikon ⋮ di sebelah fail itu, kemudian klik Keep (Simpan). Fail ini selamat. Amaran itu keluar kerana app kami masih baru.

Bahagian 2: Pasang

  1. Buka fail yang dimuat turun. Klik ikon Muat turun di penjuru kanan atas Chrome, kemudian klik Global-Streamer-Setup.exe. Atau buka folder Downloads dan double-click fail itu.

  2. Jika Windows menunjukkan skrin biru "Windows protected your PC":

    • Klik More info (Maklumat lanjut).
    • Klik butang Run anyway (Jalankan juga).

  3. Skrin pemasangan akan dibuka. Ikut langkah ini:

    • Jika ditanya "Install for anyone using this computer" atau "Only for me", pilih Only for me, kemudian klik Next.
    • Klik Next pada pilihan folder. Tidak perlu tukar apa-apa.
    • Klik Install dan tunggu sehingga selesai (biasanya kurang 1 minit).
    • Pastikan ada tanda ✔ pada Run Global Streamer, kemudian klik Finish.

Bahagian 3: Guna app

  1. Global Streamer akan terbuka sendiri. Lain kali, buka app dengan double-click ikon Global Streamer di Desktop, atau cari Global Streamer di menu Start.

  2. Mula guna: pilih game, masukkan URL dan Stream Key platform anda (TikTok, Facebook atau YouTube), kemudian tekan MULA LIVE.

Bahagian 4: Kemas kini

Bila ada versi baru, anda tidak perlu muat turun semula. Klik sahaja butang kemas kini di bahagian atas (header) app, dan app akan kemas kini sendiri.
