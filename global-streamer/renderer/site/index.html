VERSI BETA

Studio live untuk streamer Mobile Legends

Siarkan serentak ke TikTok, Facebook dan YouTube dengan satu pengekodan. Susun atur menegak 9:16, efek kill dan victory, chat gabungan, serta pembantu draft yang membaca skrin game anda.

Muat turun untuk WindowsCuba versi web

Siaran sebenar ke platform memerlukan app Windows. Versi web ialah mod demo (pelayar tidak boleh menghantar RTMP). Tiada pendaftaran diperlukan.

Apa yang ada

Semua yang disenaraikan sudah dibina dan diuji dalam pembangunan. Beberapa ciri bergantung pada rupa UI game dan boleh dikalibrasi.

📡

Satu pengekodan, banyak destinasi

Hantar ke TikTok, Facebook, YouTube dan RTMP lain serentak. Destinasi yang terputus disambung semula sendiri tanpa mengganggu yang lain.

📱

Menegak 9:16 dan mendatar

12 template, 8 tema warna dan reka bentuk, dan saiz output dari 480p hingga 4K. Pengekod GPU (NVENC, Quick Sync, AMF) dengan sandaran CPU.

🎮

Efek khusus Mobile Legends

Kill, multi-kill, mati, victory, defeat, beli item dan item penuh. Dicetus automatik daripada capture card, atau manual dengan pintasan papan kekunci.

🧠

Pembantu draft

Membaca pick dan ban daripada skrin draft, mencadangkan pick dan ban berdasarkan meta tournament terkini, lane kosong, counter dan padanan. Boleh dibetulkan dan belajar.

🏆

Tournament automatik

Jadual, skor, keputusan dan juara MPL, MSC dan M-series. Perlawanan semasa dipilih automatik dan boleh dipaparkan sebagai papan skor pada siaran.

💬

Chat gabungan dan alert

YouTube (API rasmi), Facebook (Graph API rasmi) dan TikTok melalui geganti pilihan anda. Super Chat, gift, follow dan like menggerakkan alert, boss game dan Top Like.

🎛️

Studio seperti OBS

Scene, sumber, mixer audio berbilang input, mod Normal dan Studio, pemilih skrin dan tetingkap, rakaman tempatan dan widget (jam, W/L, bar status, giliran mabar).

🔒

Privasi

Stream key tidak pernah disimpan di pelayan. Dalam app Windows ia disulitkan oleh sistem pengendalian. Hero dan panel peribadi tidak masuk ke siaran.

🌐

Dwibahasa

Antara muka dan teks pada siaran dalam Bahasa Melayu dan English, boleh dipilih berasingan.

Cara guna

Pasang dan sambung capture card
Pilih capture card sebagai sumber Game, kamera sebagai sumber Kamera.
Pilih template dan masukkan stream key
Wizard 'Sediakan Live' membimbing 4 langkah. Tampal Server URL dan Stream Key daripada setiap platform.
Hidupkan pengesanan automatik (pilihan)
Draft, kill, item, victory dan defeat dikesan daripada skrin game dan memicu efek.
Mula Live
Uji dengan siaran peribadi atau tidak disenaraikan dahulu sebelum siaran awam.

Soalan lazim

Adakah saya perlu daftar atau log masuk?

Tidak. App boleh digunakan terus tanpa akaun.

Mengapa versi web tidak boleh siaran sebenar?

Pelayar tidak boleh menghantar RTMP. Siaran sebenar menggunakan FFmpeg dalam app Windows.

Bagaimana dengan chat TikTok?

TikTok tidak menyediakan API rasmi untuk chat LIVE, jadi app menyambung melalui geganti WebSocket yang anda jalankan sendiri. YouTube dan Facebook menggunakan API rasmi.

Adakah pengesanan automatik tepat?

Ban, kill, mati, item, victory dan defeat dikesan dengan baik pada rakaman ujian. Potret pick dalam draft bergantung pada skin dan versi game: sistem boleh dibetulkan dan belajar daripada pembetulan anda. Anda boleh mengkalibrasi kawasan jika peranti berbeza.

Berapa harganya?

Versi beta. Maklumat harga dan lesen akan diumumkan.
