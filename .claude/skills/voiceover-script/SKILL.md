# Voiceover Script

## Base prompt
> Write a voiceover script about [topic] for a [duration] video in a [tone] voice. Short spoken sentences, pause marks and emphasis on key words.

## How to apply
- Write for the ear: short sentences, contractions, no jargon; read-aloud test every line.
- Mark pauses `/`, emphasis in CAPS, and per-beat timing; keep ~150 words/minute.
- Keep one idea per line so it maps 1:1 to storyboard beats and caption timestamps.
- Reply in the user's language; end with recording tips (room, distance, retakes).
