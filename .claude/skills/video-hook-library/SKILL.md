# Perpustakaan Hook (BM)

| Jenis | Formula | Contoh |
|---|---|---|
| Soalan | "Tahu tak kenapa ___?" | "Tahu tak kenapa bisnes kau tak jalan?" |
| Nombor | "[N] cara untuk ___" | "3 cara cari idea bisnes" |
| Kesilapan | "Jangan buat ___ lagi" | "Jangan upload video macam ni lagi" |
| Sebelum/Selepas | "Rakaman biasa vs diedit" | split screen |
| Berani | Kenyataan melawan arus | "Followers ramai tak bermakna untung" |
| Rahsia | "Tak ramai tahu ___" | "Trik ni tak ramai tahu" |

Peraturan: maksimum ~8 patah perkataan, visual bergerak dalam 0.5 saat, teks besar, tiada intro "Hai semua".
Pilih hook ikut topik; jangan paksa formula. Beri 3 pilihan dan cadangkan satu.
