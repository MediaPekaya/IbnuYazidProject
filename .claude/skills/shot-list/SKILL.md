# Shot List

## Base prompt
> Create a shot list for a video about [topic]: shot number, shot type, angle, location, props, action/line, and B-roll ideas. Group shots by location to save filming time.

## How to apply
- Use `templates/video/shot-list.md` as the output layout.
- Group by location and lighting, not script order; mark the script line each shot covers.
- Include must-have B-roll, a safety shot per scene, and gear/props checklist.
- Reply in the user's language; end with a filming-day order of work.
