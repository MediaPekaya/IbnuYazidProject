# Short-Form Video Script

## Base prompt
> Write [number] short-form video scripts (15-60 s) on [topic] for [platform]. Each: 3-second hook, 3-5 punchy beats, one CTA, on-screen text and caption with hashtags.

## How to apply
- Use `templates/video/short-form-script.md`. Hook must work with sound off (on-screen text).
- One idea per video; aim for ~2.5 words/second spoken, so 30 s is about 75 words.
- Offer 3 alternative hooks per script (question, bold claim, number/story).
- Reply in the user's language (natural Malay, not Indonesian wording). Finish with a posting-time/next-step suggestion.
