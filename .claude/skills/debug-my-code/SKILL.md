# 11. Debug My Code

## Base prompt
> Find and fix the errors in this code. Explain what was wrong and provide the corrected version.

## How to apply
- Fill every `[placeholder]` from the user's request; if missing, infer sensibly or ask once.
- Reply in the user's language (Bahasa Melayu or English); keep tone practical, not generic.
- Adapt depth/format to the context of the current repo/project instead of following the prompt rigidly.
- Finish with a concrete next step.
