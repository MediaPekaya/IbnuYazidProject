# Skrip Video BM

1. Tanya (atau ambil dari konteks): topik, sasaran penonton, tujuan (jual / didik / hiburan), tempoh.
2. Guna `templates/video/docs/script-template.md`.
3. Struktur: **Hook (0-2s)** -> **Masalah** -> **Isi (2-4 beat)** -> **Bukti/angka** -> **CTA**.
4. Satu beat = satu idea = 3-8 saat = kira-kira 8-20 patah perkataan.
5. Bahasa: Melayu santai Malaysia ("macam ni", "buat", "senang"), bukan Indonesia. Elak ayat panjang.
6. Jika user ada rakaman suara sendiri, JANGAN tulis semula; guna transkrip dia dan hanya cadangkan pemotongan.
7. Akhir skrip, beri jadual: beat -> ayat -> visual cadangan -> teks skrin.
