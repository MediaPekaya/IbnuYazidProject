Firebase belum disambung. Isi FIREBASE_CONFIG dalam fail ini (dan dalam index.html) untuk log masuk sebenar.
  1. Cipta projek percuma di console.firebase.google.com (pelan Spark).
  2. Aktifkan Authentication → Email/Password dan cipta akaun admin.
  3. Aktifkan Firestore dan Realtime Database, kemudian tampal peraturan (rules) yang disediakan.
  4. Salin UID admin. Cipta dokumen Firestore admins/{UID} dan nod Realtime DB admins/{UID}: true.
  5. Tampal konfigurasi web app ke FIREBASE_CONFIG.
