# Media Digital AI & Vibe Coding — Slide Presentation

Buka `index.html` dalam Chrome / Edge / Safari (tak perlu pasang apa-apa). Saiz slide 1920×1080, auto-skala ikut skrin.

| Kawalan | Fungsi |
|---|---|
| Klik / Space / Enter / → | Slide seterusnya |
| ← / Backspace | Slide sebelumnya |
| Home / End | Slide pertama / terakhir |
| F | Skrin penuh |
| M | Senyap / buka bunyi |
| Swipe (skrin sentuh) | Seterusnya / sebelumnya |

Bunyi popup, whoosh dan ketikan dijana terus dalam pelayar (WebAudio), tiada fail audio. Fon dimuat dari Google Fonts; tanpa internet, fon sistem digunakan.
